## Критичные для live-пилота замечания

1. **Проверка формы ослаблена.** `app/services/kwork_browser.py:1048` больше не отказывает при несовпадении видимого редактора и textarea, может выбрать первый подходящий срок и ищет совпадающую цену вне привязки к той же форме. `:1144`/`:1188` автоматически меняют поля заголовка/оплаты, которые не включены в approval snapshot. Несколько browser contract tests подтверждают пропуск отсутствующих/дублированных/посторонних полей. До исправления live submit не принимать.
2. **Показанный и закреплённый текст могут расходиться.** `app/services/approval_snapshot.py:19` нормализует текст при формировании snapshot, а `app/services/review_reissue.py:97` показывает исходный `proposal.content`. Sender требует совпадения с исходным текстом (`app/services/proposal_sender.py:165`), поэтому часть корректно одобренных откликов блокируется `approved_payload_mismatch` даже в dry-run. Две разные версии исходной строки с разными ценами могут создавать одинаковый snapshot; тестовый пример подтверждён. C042 переоткрыт.
3. **Ставка ниже минимума ИИ.** `app/utils/formatting.py:87` выбирает минимум из конкурентной ставки и оценённой цены. Пример: ИИ 1500 ₽, бюджет 1000–3000 ₽ → 500 ₽. Это противоречит согласованному «минимуму, который ИИ сочтёт разумным». Текущий новый тест намеренно утверждает обратное.
4. **Автозамена цены удаляет содержимое.** `app/utils/formatting.py:176` regex охватывает переносы строк и может удалить приветствие и описание работы вместе с ценой. Пример `Привет\\nСделаю задачу\\nСтоимость 1500 ₽.` превращается только в строку цены 500 ₽. Если правильная строка цены уже есть, функция может оставить вторую противоречащую цену.
5. **Preflight неверно сообщает об успехе.** `scripts/ops_step6_preflight.py:133` игнорирует статус pilot и число `unknown_result`; при подставных 3 unknown и status exit 1 скрипт возвращает 0, если прочие проверки положительны. Условие Qdrant также использует `and`, пропуская `ok=false` при нулевом exit. `_kwork_access_gate` проверяет по существу доступность списка, а не авторизацию и возможность отправки именно выбранного заказа.
6. **Ротация scraper неполная.** `app/scrapers/kwork.py:104` запускает браузер до `try`: ошибка запуска первого proxy прерывает попытки остальных. Ошибка на поздней странице также теряет уже собранные локально записи `_scrape_listing_pages`.
