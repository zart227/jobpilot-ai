## Воспроизведённые нарушения

1. Неутверждённый draft с другим текстом: send preparation → `proceed`.
2. Два concurrent retries одного send attempt → `proceed`, `proceed`.
3. Persist результата без fencing очищает новый job claim.
4. Два hired с разными keys →100 reward вместо50.
5. После commit нового proposal →0 связанных outbox events.
6. Outbox finalization без token завершается status=sent.
7. Reconcile reply по совпадению первых40 символов →true для другого полного текста.
8. Scoring bool →1.0; filter string «true» →True; learning schema допускает unknown negative key.
9. EmbeddingUnavailableError swallowed; caller получает обычный return, pending может считаться завершённым.
10. Одинаковая model при разных dimensions даёт одинаковую collection.
11. Валидный Bearer + разный ненужный X-API-Key меняет bucket квоты.
